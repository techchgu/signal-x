# 3–5 minute live demo script

## 0:00–0:30 — Set context

Open the Streamlit app. Explain that SignalX collects public sources and filing-backed annual metrics; it does not present an unverified hypothesis as a discovery.

## 0:30–1:00 — Show the saved demo

Choose **Demo — saved evidence**, enter no API key, and click **Run Research**. Point out the saved-evidence warning, illustrative values, evidence IDs, Python calculation, and Markdown download. State that this path performs no live search.

## 1:00–3:30 — Run the Microsoft pilot

Choose **Live research**. Ask: “Does Microsoft's revenue growth align with its operating cash flow growth, and what public evidence could explain any divergence?” Run research with internet and SEC access available. Show the stage trace, source evidence statuses, SEC filing links, fiscal periods, growth calculations, free cash flow if compatible, limitations, and verification gaps.

If the network or SEC request fails, use the explicit error and unavailable-data result as the demonstration; do not substitute demo values into the live result.

## 3:30–4:30 — Inspect the report

Show the evidence IDs alongside the clickable source links and calculation formulas. Download the Markdown report and explain that the growth difference is a calculation, while its cause remains a hypothesis requiring independent evidence.

## 4:30–5:00 — Close

Open **Claim verification details** and point out unresolved claims and alternative explanations. Close with the limitations: incomplete search coverage, heuristic verification, supported US issuer scope, and no investment advice.
