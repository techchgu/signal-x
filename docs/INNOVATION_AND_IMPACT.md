# Innovation and expected impact

## What is distinctive

SIGNALX makes source provenance part of the research object. Search snippets are treated as discovery aids; retrieved excerpts carry source IDs and URLs; SEC facts retain filing accessions, annual periods, units, and extraction status. Python performs calculations after compatibility checks. Reports expose evidence gaps and unresolved claims rather than presenting retrieval as verification.

## Expected use

The prototype can help a student or analyst move from a question to a reviewable set of sources and comparable annual measures more quickly. The report and trace make it easier for another person to inspect the same evidence and reproduce arithmetic.

## Impact limits

No measured time savings, accuracy improvement, user study, or investment outcome is claimed. Search coverage is incomplete, SEC tags require careful selection, and source independence and explanations still need human review. Public evidence and an optional language model may be incomplete or wrong.

## Responsible-use position

Retrieved page text and model output are treated as untrusted. Missing or incompatible values are disclosed. The app does not bypass authentication or access controls, and the saved demo is explicitly labeled as illustrative.
